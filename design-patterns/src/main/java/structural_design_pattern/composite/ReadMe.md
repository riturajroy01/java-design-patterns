
# Composite Design Pattern - Computer Device

## When you have a group of objects that you want to treat as a single object,
you can use the compositedesignpattern.Composite Design Pattern. This pattern allows you to compose objects
into tree structures to represent part-whole hierarchies.
It lets clients treat individual objects and compositions of objects uniformly.

## When you have an object and under that you have multiple objects which can be leaf or composite objects
and you want to do same operation either on  leaf or composite objects.
If it is a leaf object, it will perform the operation on that object and simply print price for example
and if it is a composite object, it will perform the operation on all the child objects of that composite object and print price of all leaf nodes.
